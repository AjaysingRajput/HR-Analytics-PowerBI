# HR-Analytics-PowerBI
📌 Description:
This HR Analytics Dashboard in Power BI provides insights into employee attrition trends. It visualizes key HR metrics such as attrition rate, job role impact, salary distribution, and demographic factors to help organizations make data-driven decisions.

🔹 Key Features:
📊 Attrition Analysis by education, age, gender, and job role
💰 Salary Slab Breakdown to identify trends in retention
📅 Years at Company vs. Attrition Rate
📈 Interactive Visuals for better decision-making

README.md with project details
